# 🌐 Personal Portfolio - Moch Afiful Islam

Repository ini berisi kode sumber (*source code*) untuk website portofolio pribadi saya. Website ini dirancang untuk menampilkan latar belakang, keahlian, serta proyek-proyek di bidang **Computer Vision**, **Machine Learning**, dan **Computational Mathematics**.

🔗 **Live Demo:** [mochafifulislam.github.io/portfolio](https://mochafifulislam.github.io/portfolio/)

---

## ✨ Fitur Utama

- **Hero & About Me:** Ringkasan latar belakang akademis di Universitas Brawijaya dan fokus minat riset/karir.
- **Featured Projects:** Galeri proyek pilihan lengkap dengan deskripsi, *tech stack*, dan tautan ke repository/demo.
- **Skills & Tools:** Visualisasi keahlian di bidang pemrograman, pustaka *Machine Learning*, dan alat pengembangan.
- **Contact & Social Links:** Akses cepat untuk terhubung via LinkedIn, GitHub, Instagram, dan Email.
- **Responsive Design:** Tampilan adaptif yang nyaman diakses dari perangkat mobile maupun desktop.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling/Framework:** Tailwind CSS
- **Icons & Fonts:** FontAwesome / Google Fonts
- **Deployment:** GitHub Pages

---

## 📌 Proyek yang Ditampilkan dalam Portofolio

1. **Segmentasi Nasabah BSI KCP Batamindo**
   - *Metode:* K-Means Clustering
   - *Deskripsi:* Pengelompokan karakteristik nasabah untuk analisis strategi layanan dan pemasaran perbankan.

2. **Klasifikasi 7 Lesi Kanker Kulit**
   - *Metode:* VGG19 (Transfer Learning)
   - *Deskripsi:* Klasifikasi citra medis medis untuk mendeteksi jenis lesi kulit secara akurat.

3. **Deteksi & Penghitungan Kendaraan Bermotor (CCTV Malang)**
   - *Metode:* YOLOv12 & OpenCV
   - *Deskripsi:* Sistem pemantauan lalu lintas otomatis secara *real-time* berbasis rekaman CCTV kota.

4. **Identifikasi Varietas Cabai**
   - *Metode:* Deep Ensemble Learning
   - *Deskripsi:* Model kombinasi deep learning untuk mengklasifikasikan jenis varietas cabai secara presisi.
